# HTML Map Viewer

The HTML Map Viewer is a single web page that loads the SPL basemap in your browser. There is nothing to install and no code to write. Open the viewer, enter the gateway base URL and the API key you were given, and the map loads with your key attached to every request. It is the quickest way to check that your key works before you write any code.

<ViewerLinks />

:::note Which keys work
The viewer sends your key in the `{{gatewayKeyHeader}}` header, so it works with keys issued for the SPL API gateway. See [API Keys & Authentication](/docs/docs/maps/api-keys).
:::

## What you need

- The viewer page, `SPL_Map_Viewer.html`, from the buttons above. **Open the viewer** starts it with the base URL already filled in. **Download** saves the file, which you can then double-click to open it in your browser.
- Your API key. If you do not have one yet, contact the SPL team.
- The gateway base URL. For this documentation it is `{{gatewayBase}}`.
- A modern browser with an internet connection. The viewer loads MapLibre GL JS from a public CDN, so it does not work offline.

:::caution The viewer calls the gateway from your browser
The viewer is a web page, so it only works when it is opened from a website that the gateway permits. A downloaded copy opened from disk is blocked by the browser. If **Open the viewer** above does not load the map, ask the SPL team to permit this website for your key. See [API Keys & Authentication](/docs/docs/maps/api-keys).
:::

## Step 1: Open the viewer

1. Click **Open the viewer** above. The page opens in a new tab.
2. A **Connect to the map gateway** dialog opens over the map.

If you downloaded the file instead, double-click it to open it in your browser. You do not need a web server.

## Step 2: Enter your base URL and key

Fill in the three fields and click **Load map**.

| Field | What to enter |
| --- | --- |
| **Base URL** | The gateway URL up to, but not including, `/styles/...`. Here: `{{gatewayBase}}` |
| **API key** | The key you were given. It is kept only for this browser tab. |
| **Style ID** | The style to load. The default is `spl_bgmaps`. Other styles are `spl_dark` and `spl_satellite`, each with `_en` and `_ar` for one label language. |

Use **Show** to display the key and check it for typos.

The viewer checks your entries before it draws the map, so a wrong key or URL is reported in the dialog instead of leaving you with a blank map.

## Step 3: Use the map

After the map loads, a panel in the top-left corner shows your connection (the style ID and the gateway) and the status of the map.

**Go to** moves the map to a place: Saudi Arabia, Riyadh, Jeddah, Makkah, Dammam, Riyadh street level, and two vertical address examples (VA and KACST).

**Status** shows what the viewer is doing.

| Status | Meaning |
| --- | --- |
| Style | The name of the loaded style and its number of layers. |
| Tiles | How many map tiles have loaded. |
| 429 retries | How many requests were sent again after the gateway rate limited them. |
| Errors | How many requests failed. Their messages are listed under the status. |
| View | The map center (latitude, longitude) and the current zoom level. |

### Move around the map

- Drag the map to move it.
- Use the scroll wheel, or the **+** and **-** buttons in the top-right corner, to zoom in and out.
- Click the compass button in the same corner to point the map back north.

### Do more with the viewer

- **Change**, next to the connection, reopens the dialog so you can switch to another base URL, key or style.
- Click any feature on the map to inspect its attributes.
- The fullscreen and locate buttons sit under the zoom buttons in the top-right corner, and a scale bar is in the bottom-left corner.
- On a screen narrower than 600 pixels the panel moves to the bottom and can be folded away with **Hide**.

## How it works

The viewer is a working reference for the steps in [Using SPL Maps in JavaScript](/docs/docs/maps/using-spl-maps).

1. **Your entries are checked first.** The viewer requests the style at `{base URL}/styles/{style ID}/style.json` and then one of its tile sources, sending your key with both. If either request fails, the dialog stays open and explains why.
2. **Every request to your base URL carries your key.** The style, the map tiles, the label fonts (glyphs) and the icons (sprites) are all loaded from the gateway with the `{{gatewayKeyHeader}}` header. Requests to other hosts, such as the CDN, are sent without it.
3. **Addresses inside the style are rewritten.** The style refers to an internal host for its tiles, fonts and icons. The viewer maps those addresses back onto your base URL.
4. **Requests are paced.** Requests are sent one at a time with a short gap between them. When the gateway answers `429 Too Many Requests`, the viewer waits and tries again, up to 6 times per request, waiting a little longer each time. Every retry is counted under **429 retries**.
5. **Failures are reported.** Failed requests are counted under **Errors**, and up to 20 different messages are listed in the panel.

### What the viewer remembers

After a successful connection the viewer stores your base URL and style ID in the browser, and keeps your key only for the current tab. When you reload the page in the same tab it reconnects by itself. Close the tab to clear the key.

:::caution The key is used in your browser
The viewer sends your key from your browser, which is fine for checking your access and looking at the map. For your own application, follow the best practices in [API Keys & Authentication](/docs/docs/maps/api-keys).
:::

## Troubleshooting

The dialog explains why a connection failed. The panel reports requests that fail after the map has loaded. A message starts with **Style** or **Map data (TileJSON)**, depending on which check failed.

| Message | Cause and what to do |
| --- | --- |
| `... was rejected (HTTP 401)` | The key is missing or not valid. Click **Show** and check the key, then confirm with the SPL team that it is active. |
| `... was refused (HTTP 403): the key has used up its call volume quota` | The key is valid, but its quota is used up. The message says when it is replenished. Ask the SPL team for a higher quota if you need one. |
| `... not found (HTTP 404)` | Nothing is served at that address. Check the base URL, including its path, and the style ID. |
| `The gateway is rate limiting requests (HTTP 429)` | The gateway is limiting the number of requests. Wait a minute and click **Load map** again. |
| `The gateway returned a server error (HTTP 5xx)` | There is a problem on the gateway. Try again later. If it persists, contact the SPL team. |
| `Couldn't get a response from ...` | The browser blocked the request because the viewer is not on a website that the gateway permits, or the gateway did not answer. Check the base URL for typos, including the path, and check your connection. |
| `... did not return JSON` | The address is not the map gateway. Check that the base URL points at the map gateway. |
| `... is not a MapLibre style` | The address answered, but not with a map style. Check the base URL and the style ID. |
| `Map data requests are being rejected` in the panel | The key loads the style but not the map data. The key may not have access to the tile, font and icon APIs, or its call volume quota is used up. |
